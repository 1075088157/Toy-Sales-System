# Toy Sales System (Smiles and Sunshine Toys)

A full-stack toy e-commerce web app with **Customer** and **Sales Staff** roles.

## Tech Stack
PHP, MySQL, JavaScript, jQuery, AJAX, HTML, CSS

## Core Features
- Customer: register/login, browse/search toys, wishlist, submit orders, track order status
- Sales Staff: view all orders, update order status and estimated delivery date
- Secure login with hashed passwords and PDO prepared statements

## How to Run
1. Import `smile_sunshine.sql` into MySQL.
2. Configure database in `php/db_connection.php`.
3. Put the project in `htdocs/` and start Apache + MySQL.
4. Open `http://localhost/Toy Sales System`.
